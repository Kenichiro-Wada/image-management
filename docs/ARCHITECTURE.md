## Stack構成

### インフラレイヤー（基盤）

#### 1. InfraStorageStack
- S3バケット（画像ストレージ）
- S3バケット（サムネイル）
- S3バケット（管理画面フロントエンド）
- S3バケット（ビューアーフロントエンド）
- CloudFrontディストリビューション（4つ）

#### 2. InfraDatabaseStack
- DynamoDBテーブル（画像メタデータ）
  - GSI1: ユーザー別画像一覧
  - GSI2: 公開画像一覧
- DynamoDBテーブル（タグ管理）
- DynamoDBテーブル（ユーザー情報）

#### 3. InfraAuthStack
- Cognito User Pool
- ユーザーグループ（System_Admin、Image_Manager、Regular_User）
- App Client

### アプリケーションレイヤー

#### 4. AppAdminStack
- API Gateway（管理画面用）
- Lambda関数（画像アップロード）
- Lambda関数（画像管理）
- Lambda関数（タグ管理）
- Lambda関数（認証）
- Lambda関数（画像リサイズ）

#### 5. AppViewerStack
- API Gateway（ビューアー用）
- Lambda関数（公開画像一覧）
- Lambda関数（画像検索）

## データフロー

### 画像アップロードフロー

```
1. ユーザー → CloudFront → S3（管理画面）
2. ユーザー → API Gateway → Lambda（アップロード）
3. Lambda → S3（画像ストレージ）
4. Lambda → DynamoDB（メタデータ保存）
5. S3イベント → Lambda（リサイズ）
6. Lambda → S3（サムネイル保存）
```

### 画像閲覧フロー

```
1. ユーザー → CloudFront → S3（ビューアー）
2. ユーザー → API Gateway → Lambda（画像一覧）
3. Lambda → DynamoDB（メタデータ取得）
4. Lambda → ユーザー（画像一覧）
5. ユーザー → CloudFront → S3（画像取得）
```

## セキュリティ

### 認証・認可

- **管理画面**: Cognito認証必須
- **ビューアー**: 認証不要（公開画像のみ）
- **ロール別アクセス制御**:
  - System_Admin: 全ての操作が可能
  - Image_Manager: 閲覧、公開状態変更、ダウンロードが可能
  - Regular_User: 自分の画像のみ操作可能

### ネットワークセキュリティ

- 全てのAPI通信はHTTPS
- CloudFrontでのWAF設定（推奨）
- S3バケットはプライベート（CloudFrontからのみアクセス可能）

### データ保護

- S3バケットのバージョニング有効化
- DynamoDBのポイントインタイムリカバリ有効化
- CloudWatch Logsでの監査ログ記録

## スケーラビリティ

### 自動スケーリング

- **Lambda**: 自動スケーリング（同時実行数: 1000）
- **DynamoDB**: オンデマンドモード（自動スケーリング）
- **CloudFront**: グローバルエッジロケーション

### パフォーマンス最適化

- CloudFrontでのキャッシング
- DynamoDBのGSI活用
- Lambda関数のコールドスタート対策
- S3の転送加速（オプション）

## コスト最適化

- S3のライフサイクルポリシー（古い画像をGlacierに移動）
- CloudFrontのキャッシュ最適化
- Lambda関数のメモリ最適化
- DynamoDBのオンデマンドモード
