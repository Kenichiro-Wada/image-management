## 注意事項

### 技術スタック
- **インフラ**: AWS CDK（TypeScript）
- **バックエンド**: Node.js 22.x LTS、TypeScript
- **フロントエンド**: React 18、TypeScript、Vite
- **テスト**: Jest、fast-check、Playwright
- **画像処理**: Sharp.js
- **認証**: AWS Cognito、AWS Amplify

### 開発ガイドライン
- すべてのコードはTypeScriptで記述
- AWS CDKはTypeScriptで記述
- Lambda関数はNode.js 22.xランタイムを使用
- ESLintとPrettierを使用したコード品質管理
- コミット前にユニットテストを実行
- プロパティベーステストは最低100回実行
- すべてのAPIエンドポイントにエラーハンドリングを実装
- 環境変数を使用した設定管理
- CDK Stackは論理的に分割（ネットワーク、データベース、アプリケーション等）

### セキュリティ要件
- すべてのAPI通信はHTTPS
- Cognito認証トークンの検証
- ロール別アクセス制御の実装
- S3バケットのアクセス制御設定
- 機密情報の環境変数管理
