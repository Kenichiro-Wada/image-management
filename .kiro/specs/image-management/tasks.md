# 実装タスク（Stack分割版）

## 概要

AWS上で動作するサーバーレス画像管理システムの実装タスクリストです。
CDK Stackをレイヤー別（インフラ/アプリケーション）に分割し、管理画面とビューアーを分離した構成で実装を進めます。

## Stack構成

### インフラレイヤー（基盤）
1. **InfraStorageStack**: S3バケット、CloudFrontディストリビューション
2. **InfraDatabaseStack**: DynamoDBテーブル
3. **InfraAuthStack**: Cognito User Pool、ユーザーグループ

### アプリケーションレイヤー
4. **AppAdminStack**: 管理画面用API Gateway、Lambda関数
5. **AppViewerStack**: ビューアー用API Gateway、Lambda関数

## 注意事項

### 技術スタック
- **インフラ**: AWS CDK（TypeScript）
- **バックエンド**: Node.js 24.x LTS、TypeScript
- **フロントエンド**: React 18、TypeScript、Vite
- **テスト**: Jest、fast-check、Playwright
- **画像処理**: Sharp.js
- **認証**: AWS Cognito、AWS Amplify

### 開発ガイドライン
- すべてのコードはTypeScriptで記述
- AWS CDKはTypeScriptで記述
- Lambda関数はNode.js 24.xランタイムを使用
- ESLintとPrettierを使用したコード品質管理
- コミット前にユニットテストを実行
- プロパティベーステストは最低100回実行
- すべてのAPIエンドポイントにエラーハンドリングを実装
- 環境変数を使用した設定管理
- CDK Stackはレイヤー別に分割（インフラ/アプリケーション）

### セキュリティ要件
- すべてのAPI通信はHTTPS
- Cognito認証トークンの検証
- ロール別アクセス制御の実装
- S3バケットのアクセス制御設定
- 機密情報の環境変数管理

### 環境設定
- **dev**: 開発環境
- **prd**: 本番環境
